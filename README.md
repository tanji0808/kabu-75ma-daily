# 75日線ブレイク候補（東証プライム・毎日自動更新）

平日の 16:40（日本時間）に GitHub Actions が東証プライム全銘柄の株価を取得し、
GitHub Pages にスクリーナー画面（`web/index.html`）として公開します。
開くと「3ヶ月以上下落したあと、75日線を下から突き抜けそう／抜けた直後」の銘柄が表示され、
条件を変えて絞り込んだり、チャートを見たりできます。候補のカード表示は `cards.html` です。

## 条件（`kabu_75ma_search.py` の先頭「設定」で変更できます）
- 東証プライム、直近の出来高 30万株以上
- 75日線が3ヶ月前より2%以上低い／直近3ヶ月の75%以上の日で終値が75日線の下／半年高値から15%以上下落
- 突破目前：終値が75日線の5%下〜75日線で、5日前より上昇
- 突破直後：5営業日以内に75日線を上抜け、上抜け幅3%以内

## 初回の設定
1. Settings → Pages → Source を **GitHub Actions** にする
2. Actions タブ → 「75日線ブレイク候補を毎日更新」→ Run workflow で一度手動実行

結果は売買のおすすめではありません。データ：Yahoo Finance（yfinance）／東証上場銘柄一覧
